# 登录与浏览器操作协议

## 1. 登录

站点：`https://sit-padmin-demo.shopex123.com/`

### 1.1 步骤

1. `navigate_page` 打开站点，等待登录卡片出现。
2. 切到 **「账号登录」** Tab（默认可能是手机号登录）。
3. 填写：
   - **用户名** = 输入的账号
   - **密码** = 输入的密码
   - **租户编码** = 输入的租户号。若字段未显示，说明域名已带租户；若显示了但与输入不同，先清空再填。
4. **登录端口**（若显示单选）：展开选项，选择名称含「管理端 / 平台端 / 后台 / 运营」的一项；只有一个选项时直接选中。选错会提示端口无权限，回到此步换选。
5. **滑块验证**：
   - 找到滑块把手，`drag` 到轨道最右侧（留 2–4px）。
   - 成功标识：出现「验证成功」或滑块变绿。
   - 失败会自动复位；最多重试 2 次，仍失败则暂停请用户手动完成，用户确认后继续。
6. 点 **「登录」**，等待进入后台。以左侧菜单/工作台渲染为准，不以 URL 变化为准。
7. 若弹出「首次登录，请先修改密码」：暂停，向用户索取新密码 → 输入新密码与确认 → 提交 → 继续。**新密码同样不落盘。**

### 1.2 登录异常

| 现象 | 处理 |
|---|---|
| 「用户名或密码错误」 | 停止，原样回报，不试其它账号/租户 |
| 「租户编码不存在」 | 与用户核对租户号；不猜测 |
| 滑块反复失败 | 重试 2 次后交还用户手动完成 |
| 停留在租户选择页 | 选与租户号匹配的租户进入 |
| 登录后空白/401 | 刷新一次；仍失败则重新登录一次；再失败停止 |

## 2. 页面导航

- 登录后优先用完整路径直达，如 `https://sit-padmin-demo.shopex123.com/eXproduct/scopes/manage`。
- 直达后必须确认页面标题或首屏按钮符合预期；出现 404/空白则改用左侧菜单进入。
- 菜单可能按套餐裁剪：若目标页在菜单中不存在，记录「环境未开通」并停止该步骤，不伪造数据。

## 3. 元素定位

1. 每次操作前 `take_snapshot`，用可访问性树中的 role/name 定位；ref 会失效，操作后重新快照。
2. 优先按**可见中文文案**定位（按钮名、label、Tab 名），其次按占位符。
3. 禁止按截图坐标盲点；截图只用于留档和人工判断。
4. 弹层（下拉、抽屉、对话框）通常 teleport 到 body 末尾，快照中仍可见，按文本点选。

### 控件操作

| 控件 | 操作 |
|---|---|
| 输入框 | `fill` 清空并输入；数字框点入后全选输入，按 Enter 或点空白提交 |
| 单选/开关 | 点整行 label 或开关本体，快照确认选中态 |
| `el-select` | 点输入框 → 等浮层 → 点选项文本；可搜索的先输入再点 |
| 级联 | 点开 → 逐列点选 → 等待下一列出现 |
| 树 | 点箭头展开；节点右侧 `+` 可能需要 hover 才出现 |
| 日期区间 | 直接填 `YYYY-MM-DD` 到起止输入框，按 Enter |
| 富文本 | 点编辑区输入纯文本；不要粘贴 HTML |
| 上传 | 点上传区域 → 对当前弹层内 `input[type=file]` 调 `upload_file` 传绝对路径 → 等缩略图 |
| 批量勾选 | 点表头复选框，快照确认行选中数 |

上传时若页面有多个 file input：先 `evaluate_script` 列出可见 input 的位置/accept，选与当前字段匹配的那个；一次只传一个字段。

## 4. 保存与验证

- 保存类按钮：`保存`、`确定`、`提交`、`保存商品`、`保存全部`、`提交认证`、`提交审核结果`、`确定通过`。
- 成功判据：Toast（`保存成功`/`新增成功`/`操作成功`/`配置保存成功`/`已提交审核`/`已直通上线`）**或** 抽屉关闭 + 列表出现目标行。
- 失败判据：Toast 报红、字段红框、接口 4xx/5xx。
- 每次保存后重新打开/刷新列表，按**精确名称**回查，确认不是「看起来保存了」。

## 5. 排错顺序

1. 读 Toast 原文。
2. `list_console_messages` 看前端异常。
3. `list_network_requests` 找失败接口的 URL、状态码、响应 message。
4. 常见原因与修复：

| 报错 | 修复 |
|---|---|
| 名称为空/重复 | 按 dataset 精确名称重填；重复则改用 `exists` 复用 |
| 必填项未填 | 快照找红框字段补齐 |
| 下拉无选项 | 回到依赖步骤补建（品牌→品类绑定、单位、税率、运费模板等） |
| 经营范围只支持单选 | 商品表单只选一个 |
| 文件类型/大小不符 | 换 PNG/JPG，压到 2MB 内 |
| 401/登录过期 | 重新登录一次，回到当前步骤续做 |
| 权限不足 | 记录并停止该页，收尾标注 |

5. 修复后重试同一动作；仍失败则停止该步骤并在 `ledger.md` 标 `blocked`，继续不依赖它的后续步骤。

## 6. 留档

- 每完成一页：`take_screenshot` → `screenshots/<两位步骤号>-<页面简称>.png`。
- `ledger.md` 表头：`步骤 | 页面 | 对象 | 计划数 | 成功数 | 状态 | 备注`。状态只用 `done / partial / exists / blocked / skipped`。
- ledger 与 dataset 中**不得出现密码**；截图前确认密码框已失焦且为掩码。
