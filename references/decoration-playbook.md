# 装修操作手册（步骤 19–23）

装修入口页：`/eXplatform/pages/global`，按「通用 / PC 端 / 移动端」分组。本手册只用 PC 端组：头部装修、脚部装修、PC 全局样式配置、分类菜单装修。

通用规则：

1. 卡片按钮：未装修「开始装修」、已装修「继续装修」；样式卡「配置样式 / 修改样式」。
2. 设计器右上角：**载入预置模板**（仅部分区域有）、**保存**、**不保存并关闭**。改完必须点保存。
3. 保存只落配置；区域是否生效看卡片上的**启用开关**，必须打开。
4. 预置模板是**抗体/科研试剂**主题，载入后必须全量改写文案与图片，见 §6 清单。
5. 图片全部使用 `images/` 下本次生成的图，禁止保留模板默认图与外部 CDN 图。

## 19. `/eXplatform/pages/pc` PC 首页

### 19.1 建页面

1. 点 **「新增PC页面」**：

| 字段 | 必填 | 值 |
|---|---|---|
| 页面名称 | 是 | `<品牌>商城首页` |
| 排序 | 否 | 1 |
| 状态 | — | 启用 |
| 是否系统页面 | 否 | 否 |
| 备注 | 否 | 演示首页 |

提交时系统固定 `pagePath='/'`、`clientType='PC'`。

2. 列表行点 **「设计」** 进入设计器。

### 19.2 载入预置模板

1. 点顶部 **「载入预置模板」** → 确认「将用「PC 端首页」预置模板替换当前画布内容，载入后需保存才会生效。」→ **载入**。
2. 画布出现：右侧浮窗 → 图片轮播（3 张）→ 主题楼层 → 分块楼层 → 商品卡片（5 列，10 个）→ 商品区块（2 块）。
3. 点画布中的组件选中，右侧切「组件配置」逐项改。

### 19.3 替换图片与文案

| 组件 | 要改的内容 | 值 |
|---|---|---|
| 图片轮播 | 3 张图片 | `banner-01/02/03.png`（按所选风格） |
| | 跳转链接 | `/category/all`（保留模板值） |
| | 高度 / 填充 / 轮播间隔 | 保持 460 / cover / 5000ms |
| 主题楼层 | 左图 | `floor-theme.png` |
| | 标题 / 副标题 / 查看全部 | 本次行业主推主题，文案取 dataset |
| 分块楼层 | 左图 / 右图 | `floor-split-left.png` / `floor-split-right.png` |
| | 标题 / 副标题 / 两个链接名 | 本次行业场景，文案取 dataset |
| 商品卡片 | 列数 / 数量 | 5 列 / 10 个 |
| | 商品来源 | **条件查询：品牌=本次品牌**（无品牌条件则选品类=本次一级品类） |
| | 标题 / 副标题 | 如「<品牌>热销榜」「按上架热度每日更新」 |
| 商品区块 | 2 个 block 的标题 / 副标题 / 查看全部 | 两个主推场景；条件都改为本次品牌 |
| | block 主题色 | 品牌主色 / 辅助色 |
| 右侧浮窗 | 链接名 | 在线客服 / 我的订单 / 回到顶部（可保留） |

图片上传：点组件配置中的图片位 → 选择本地文件 → 等缩略图回显。一次只换一张，换完核对顺序。

### 19.4 保存与启用

1. 点 **「保存」** → Toast「配置保存成功！」。
2. 返回列表，打开该行 **状态** 开关。系统同类型页面互斥启用：开启本页会停用其它 PC 页面。
3. 回查：状态为启用，设计器内预览为本次品牌内容。

## 20. 头部装修（`/eXplatform/pages/global`）

1. PC 端组找到「头部装修」卡片 → **「开始装修 / 继续装修」**。
2. 点 **「载入预置模板」** → 确认「将用「头部装修」预置模板替换当前画布内容，载入后需保存才会生效。」→ **载入** → Toast「已载入预置模板，请检查后保存」。
3. 三栏式头部逐项改写：

| 区域 | 原内容 | 改成 |
|---|---|---|
| 顶栏左侧文字 | 快消品整箱批发 · 代理商订货平台 | 本次品牌主标语 |
| 顶栏右侧文字 | 客服电话 / 帮助中心 | 客服电话 `400-xxx-xxxx`（虚构）/ 帮助中心（保留） |
| 主功能区 LOGO | 外部 CDN 图 | 上传 `logo-site.png` |
| 搜索框 | 默认占位 | 「搜索商品 / 品牌 / 品类」 |
| 辅助导航 | 首页 / 全部商品 / 领券中心 | 保留结构，名称按品牌调整 |
| 辅助导航右侧图文 | 授权代理 · 价格可见 | 保留或改为品牌渠道语 |

4. 点 **「保存」** → 回入口页，打开「头部装修」卡片的**启用开关**。

> 只改文案与图片，不破坏栅格/搜索/购物车/个人中心组件结构。

## 21. 脚部装修（`/eXplatform/pages/global`）

1. 找「脚部装修」卡片 → **「开始装修 / 继续装修」**。
2. 若设计器顶部有 **「载入预置模板」**：点击并确认载入。
   若没有该按钮（当前版本脚部无预置入口）：首次打开会自动铺「标准页脚」，直接编辑。
3. 改写内容：

| 项 | 改成 |
|---|---|
| 公司名 | `<品牌>（演示）` 或用户提供的公司主体 |
| 简介 | 一句话品牌与渠道介绍 |
| 联系方式 | 虚构客服电话、`service@example.com`、虚构地址 |
| 导航分组 | 购物指南 / 配送方式 / 售后服务 / 关于我们（保留结构，文案贴合 B2B 订货） |
| 底栏版权 | `© 2026 <品牌> 演示环境` |
| 备案号 | 不编造真实备案号，写「演示环境 · 无备案号」或不填 |

4. 点 **「保存」** → 回入口页打开**启用开关**。

## 22. PC 全局样式配置（`/eXplatform/pages/global`）

1. 「PC全局样式配置」卡片 → **「配置样式 / 修改样式」**，打开全屏抽屉。
2. 按所选风格填写：

| 区块 | 字段 | 值 |
|---|---|---|
| 版式风格 | 15 款选 1 | A→企业门户/清晰易读；B→品牌年鉴/权威商务；C→瑞士现代/卡片模块；D→科技玻璃/极简网格 |
| 主色调与明暗 | 明暗方案 | 日间 |
| | 色调 | A→云白·企业蓝；B→石墨·中性黑/赭石·陶土；C→海蓝·青碧/青柠；D→云白/赛博 |
| 自定义主色 | 品牌主色 / 辅助色 | 可留空，由色调派生 |
| 版式微调 | 基准字号 | 默认 |
| 各端间距 | 全部 | 留空继承版式 |
| 站点名信息 | 站点中文名 | `<品牌>` 或 `<品牌>商城` |
| | 站点英文名 | `<BRAND> B2B` |
| | 副标题 | `<品牌> <行业> 官方订货平台` |
| | 主标语 | 8–16 字，如「品牌直供 · 整箱批发 · 区域授权」 |
| | 站点 LOGO | 上传 `logo-site.png` |

3. 点 **「保存」**（抽屉不关闭属正常），再关闭抽屉。
4. 回入口页打开该卡片的**启用开关**。

> 全局样式会影响前台所有页面与头部/脚部/分类菜单，保存后不要再切回其它版式。

## 23. 分类菜单装修（`/eXplatform/pages/global`）

1. 「分类菜单装修」卡片 → **「开始装修」**，设计器左侧是「分类项数据管理」，右侧是当前分类的展开内容画布。
2. 点 **「添加分类项」**，逐个填写：

| 字段 | 必填 | 值 |
|---|---|---|
| 分类名称 | 是 | 与商品一级/二级品类一致，4–6 个 |
| 分类图标 | 否 | `cat-<slug>.png` |
| 跳转链接 | 否 | `/category/all` 或 `/`（不编造外站链接） |
| 跳转方式 | — | 当前窗口 |
| 不展开弹层 | — | 关（保留展开内容） |

3. 左侧选中每个分类，右侧画布可放图片/文字（可选）；至少保证分类名称与图标正确。数量不超过页面提示的上限。
4. 点 **「保存」** → 回入口页打开**启用开关**。

校验：入口页 4 个 PC 区域均为已装修且启用；前台 PC 头部/脚部/分类菜单与首页风格一致。

## 6. 预置文案改写清单

载入任意预置模板后，全页搜索并替换以下残留（出现任意一个即不合格）：

| 禁止残留 | 替换为 |
|---|---|
| 抗体 / 一抗 / 二抗 / 病理级 IHC | 本次行业主推品类 |
| ELISA / 试剂盒 / 诊断原料 / IVD | 本次行业主推品类 |
| 科研试剂热销榜 | `<品牌>热销榜` |
| 按应用场景选购 | 按场景选购（或行业化标题） |
| 快消品整箱批发 · 代理商订货平台 | 本次品牌主标语 |
| 抗体精选 / 全部抗体 / 全部试剂 | 与分类一致的链接名 |
| 外部 CDN LOGO 图（`bbb-cdn.shopex123.com`） | `logo-site.png` |

检查方式：设计器内逐组件点开「组件配置」核对标题、副标题、链接名、图片；保存后在前台或预览中再扫一遍。
