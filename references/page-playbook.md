# 逐页操作手册（步骤 1–18）

通用约定：

- 所有名称取 `dataset.json`，保存前用列表检索按精确名称查重；已存在记 `exists` 并跳过。
- 字段表里 `*` 为必填；「状态」默认启用。
- 每步结束按「校验」回查，再进入下一步。

---

## 1. `/eXproduct/scopes/manage` 经营范围

目标：2–3 个分类 + 6–8 个经营范围，覆盖本行业主营品类。

1. 点工具栏 **「新增分类」**：分类名称*、上级分类（树选择，不选=一级）、启用状态、备注 → 保存。
2. 左侧树选中刚建的分类（**未选分类时「新增经营范围」禁用**）。
3. 点右侧 **「新增经营范围」**：

| 字段 | 必填 | 控件 | 值 |
|---|---|---|---|
| 所属分类 | 是 | 级联 | 步骤 1 的分类 |
| 经营范围 | 是 | 输入 ≤50，不能全空格 | 如「常温乳品」「礼盒渠道」 |
| 经营范围编码 | 否 | 输入 ≤30 | `SC-<缩写>-01` |
| 启用状态 | 否 | 单选 | 启用 |
| 备注 | 否 | 文本域 ≤200 | 数据集备注 |

4. 逐个分类补齐 6–8 个范围。

校验：左树分类齐全；右侧列表按分类计数正确。

校验：按分类展开标签数量正确。

目标：2–3 个类型（经销商 / 零售商 / 连锁商超等，按行业渠道调整）。

1. **「新增客户类型」**，抽屉两张卡片：

| 卡片 | 字段 | 必填 | 值 |
|---|---|---|---|
| 基本信息 | 类型名称 | 是 | ≤30，不可重名 |
| | 外部系统ID | 否 | 留空 |
| | 排序 | 否 | 递增 |
| | 启用状态 | — | 启用 |
| | 备注 | 否 | — |
| 认证资质绑定 | 绑定资质 | 否 | **留空** |

> 绑定资质会让客户认证与审核必须上传/逐项审核资质文件，演示造数默认不绑定。用户明确要求资质演示时才绑定，并同步在 dataset 中准备文件。

校验：列表出现全部类型且启用。

## 7. `/eXenterprise/user/manage` 用户注册 → 客户认证

目标：3 个注册用户并全部提交认证。Tabs：未认证 / 已认证。

### 7.1 新增用户

点 **「新增用户」**：

| 字段 | 必填 | 规则 |
|---|---|---|
| 单位名称 | 是 | 与 dataset 客户公司名一致 |
| 联系人 | 是 | 中文姓名 |
| 联系人手机号 | 是 | 11 位，`^1[3-9]\d{9}$`，不可重复 |
| 归属销售 | 否 | 留空 |
| 备注 | 否 | 如「演示数据」 |

提交后列表进入「未认证」。

### 7.2 客户认证

行操作 **「客户认证」**，抽屉内填写：

| 字段 | 必填 | 控件 | 值 |
|---|---|---|---|
| 单位名称 | 是 | 输入 ≤100 | 回填/核对用户单位名 |
| 信用代码 | 是 | 输入 15–20 位字母数字 | dataset 的 18 位统一社会信用代码 |
| 联系人 | 是 | 输入 ≤30 | 同用户 |
| 手机号 | 是 | 输入 11 位 | 同用户 |
| 邮箱 | 否 | 输入 ≤100，需格式正确 | `xx@example.com` |
| 客户类型 | 否 | 下拉 | 步骤 4 的类型 |
| 客户等级 | 否 | 下拉可搜索 | 步骤 5 的等级 |
| 所属行业 | 否 | 级联 大类 → 行业 | 步骤 6 |
| 所在地区 | 否 | 省/市/区级联 | 与客户区域同省份 |
| 资质卡片 | — | 动态 | 无绑定资质时不出现 |

点 **「提交认证」**。重复 3 个客户。

校验：未认证列表 3 条；状态为认证中/待审核。

## 8. `/eXenterprise/customers/audit` 客户认证审核

目标：3 个客户全部审核通过。Tabs：待审核 / 审核通过 / 已驳回。

> 本页**没有批量通过/多选列**，必须逐单处理。

对每条待审记录点 **「审核」**：

1. 左栏「资质清单」：逐项点 **「通过」**（无资质项时直接进入下一步）。
2. 右栏「认证通过后初始化」：

| 字段 | 必填 | 控件 | 值 |
|---|---|---|---|
| 客户等级 | 是 | 下拉 | 步骤 5 的等级 |
| 经营范围 | 是 | 多选 | 步骤 1 的范围，勾选 1–2 个 |
| 授权地区 | 是 | 省/市两级勾选 | 与客户所在区域一致 |
| 开启授信 | 否 | 开关 | 默认关；开启则必须填额度 |

3. 点 **「提交审核结果」** → 确认弹窗 **「确认提交」**。
4. 全部处理完后切「审核通过」Tab 回查 3 条；「待审核」为 0。

校验：审核通过 3；驳回 0；客户管理中的客户状态为已认证。

## 9. `/eXproduct/catalogs/manage` 商品品类

目标：1 个一级 + 2 个二级 + 4–6 个末级，最多 3 级。末级必须绑定品牌。

1. 点 **「新增一级目录」**：系统立即创建名为「新目录」的节点并打开右侧表单。
2. 右侧表单：

| 字段 | 必填 | 值 |
|---|---|---|
| 目录名称 | 是 | ≤50，取 dataset 的品类名 |
| 目录别名 | 否 | 英文别名 |
| 目录图片 | 否 | 上传 `cat-<slug>.png` |
| 启用状态 | — | 开启 |
| 前台显示 | — | 开启 |
| 备注 | 否 | — |

3. 节点 `+` 新增子目录，重复改名。
4. **末级目录额外两步**：
   - 「品类品牌」表 → **「选择品牌」** → 勾选步骤 12 的品牌 → 确定。**未绑定品牌时商品表单品牌下拉里没有它。**
   - 「品类属性」表 → 添加 1–2 个属性（如 规格/净含量/口味），非必填为佳；属性会在商品表单「类目属性」卡渲染。
5. 每个节点点 **保存**。

校验：树层级 ≤3；每个末级都能看到品牌与属性；前台显示为开。

## 16. `/eXdelivery/freight/fee` 运费模板

目标：1 个默认模板，计价方式按件数，含一条阶梯规则。

1. 点 **「新增运费模板」**，打开「运费规则」抽屉。
2. 模板信息：

| 字段 | 必填 | 值 |
|---|---|---|
| 模板名称 | 是 | ≤100，如「全国整箱配送」 |
| 发货地区 | 是 | 必须选到**市**（如 浙江省/杭州市） |
| 计价方式 | 是 | 按件数（或按重量，二选一） |
| 默认运费(元) | 否 | 如 15 |
| 备注 | 否 | — |
| 状态 | — | 启用 |

3. 运费计算规则 → **「添加地区」** 选省级，填首件/首费/续件/续费（按重量时为首重/续重，单位 kg）。
4. 需要时补固定运费或商品免邮；不配置限配地区。
5. 点 **「保存全部」**（模板 + 规则一次提交）。
6. 回列表：把该模板的 **状态** 与 **默认模板** 开关都打开（默认模板全局唯一）。

校验：列表 1 条；默认模板标记在该行；商品表单运费模板下拉可选到。

## 17. `/eXproduct/products/manage` 商品

目标：10–12 个商品，全部「可售 + 可见」。列表 Tabs：全部 / 可售 / 停售 / 待审核 / 已驳回。

点 **「新增商品」**，抽屉按卡片自上而下填写：

### 17.1 基础信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品标题 | 是 | ≤60，不可全空格；格式「品牌 系列 品名 规格」 |
| 副标题 | 否 | ≤80，一句卖点 |
| 品类 | 是 | 只能选**末级**，需已在步骤 9 绑定品牌 |
| 品牌 | 是 | 步骤 12 的品牌 |
| 系列 | 否 | 步骤 10；下拉为空则跳过 |
| 经营范围 | 是 | **只能单选**，取步骤 1 |
| 商品标签 | 否 | 多选，步骤 13 |
| 商品吊牌 | 否 | 多选，步骤 14 |

### 17.2 类目属性

按所选品类动态渲染；填写 `dataset.products[].attributes`。没有属性时整卡可能不出现。

### 17.3 方案字段

租户自定义字段，通常为空；若有必填项，用贴合商品的通用值填写。

### 17.4 图文信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品主图 | 是 | ≥1 张；上传 `product-<slug>-main.png`（实景图） |
| 商品视频 | 否 | 跳过 |
| 说明书 | 否 | 跳过 |
| 商品详情 | 否 | 上传 `product-<slug>-detail.png` |

> 等每张图缩略图回显后再继续；主图为空时保存会被拦截。

### 17.5 商品描述

添加 1 个章节：章节标题*（≤30）+ 正文*（富文本，2–4 句卖点，避免医疗/绝对化用语）。最多 10 章，标题不可重复。

### 17.6 销售规则

| 字段 | 必填 | 值 |
|---|---|---|
| 规格类型 | 是 | **单规格**（演示默认，SKU 只 1 行） |
| 销售属性 | 多规格时 | 跳过 |
| 划线价 | 否 | ≥ 基准价，如 129 |
| 基准价 | 是 | >0，如 99 |
| 单位 | 是 | 步骤 15 |
| 中包装 | 是 | ≥1，如 12 |
| 最小起订量 | 是 | ≥1，如 1 |
| 最大限购量 | 否 | 留空 |
| 重量(g) | 否 | 按箱规估算 |
| 条码 | 否 | 13 位虚构条码 |
| 销售状态 | 是 | **可售** |
| 可见状态 | 是 | **可见** |
| 运费模板 | 是 | 步骤 16 |
| 税率 | 否 | 步骤 11 |

点 **「保存商品」**：

- Toast「已提交审核」→ 进入步骤 18 审核。
- Toast「已直通上线」→ 该商品免审，仍统计成功。

重复至 10–12 个。每保存一个立即在列表按标题回查。

校验：新增数 ≥10；每个商品有主图、价格、单位、MOQ、运费模板。

## 18. `/eXproduct/products/audit` 商品审核

目标：待审核清零，可售 ≥10。Tabs：待审核 / 已驳回。

1. 切「待审核」，点表头复选框全选。
2. 点 **「批量通过」** → 确认框「批量审核确认」→ **「确定通过」**。
3. 有分页则逐页重复。
4. 回列表「可售」Tab 计数 ≥10；「待审核」为 0。

> 已驳回的不用处理；只有用户要求演示驳回流程时才用「批量驳回」并填原因（≤200）。
